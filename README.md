# Study Planner

Study Planner is a small Python project that stores a study task with its duration.

## Example

```python
from planner import add_study_task

tasks = []
add_study_task(tasks, "Physics revision", 30)
print(tasks)
```

Expected result:

```text
[{"title": "Physics revision", "minutes": 30}]
```
