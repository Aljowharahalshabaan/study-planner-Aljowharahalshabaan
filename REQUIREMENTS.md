# Project Requirements

This project is different from Gand's version. It stores a study task with its duration in minutes.

## Basic requirements

1. The repository must be private.
2. The program must reject an empty or whitespace-only task title.
3. The program must reject a duration of zero or less.
4. The program must save the task title and duration in a list.
5. The project must include a README, `.gitignore`, and MIT license.

## Remaining GitHub requirements

The following items are not complete until they appear on GitHub as real activity:

- Real issues.
- Real branches and pull requests.
- A real merge conflict and resolution.
- A peer review from a second student account.
- Screenshots of real tests and results.

Never place a password or verification code in project files or screenshots.
